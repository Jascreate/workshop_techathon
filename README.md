## 🧠 Core Curriculum & Architecture

Instead of passive slide decks, the workshop explores real-world agentic architectures through visual systems:

- **The Agent Brain (Planning & Memory)**: How LLMs decompose complex, open-ended user goals into sequential steps while maintaining dynamic state memory.
- **Tools & Function Calling**: Giving agents hands by connecting them to Python execution sandboxes, live REST APIs, web scrapers, and file systems.
- **Dynamic ReAct Loop**: Autonomous self-correction loops (`Act ➔ Observe ➔ Adjust`) to recover from runtime bugs and edge cases without human intervention.
- **LLM Orchestration & Multi-Agent Swarms**: Routing tasks between specialized agents (Planner, Researcher, Coder, Validator) for production pipelines.
